# อ่านนิยาย

เว็บอ่านนิยายแปลจากโฟลเดอร์ `data/` — Node + Express + EJS ไม่มี build step ไม่มี database

## รัน

```bash
npm install
```

```bash
npm start
```

เปิด http://localhost:3000

เปลี่ยนพอร์ต/ที่อยู่: `PORT=8080 npm start` (ค่าเริ่มต้นฟังทุก interface จึงเปิดจากมือถือใน LAN เดียวกันได้ที่ `http://<ip เครื่อง>:3000`)

### ใช้ข้อมูลจาก Translator โดยไม่ต้องมี data/ ซ้ำ

กำหนด `NOVEL_DATA_DIR` ให้ชี้ไปที่โฟลเดอร์ `data` ของ Translator ก่อนเริ่มเว็บ
(ทั้งการอ่านนิยายและ `reader.json` จะใช้ตำแหน่งนี้)

PowerShell:

```powershell
$env:NOVEL_DATA_DIR = 'C:\Users\Mac\Works\Translator\data'
npm start
```

CMD:

```bat
set "NOVEL_DATA_DIR=C:\Users\Mac\Works\Translator\data"
npm start
```

หากไม่ได้กำหนดค่า โปรแกรมจะกลับไปใช้ `read-novel/data` เพื่อให้โปรเจกต์ยังรันแบบแยกเดี่ยวได้

## หน้าเว็บ

| ที่อยู่ | ทำอะไร |
|---|---|
| `/` | ชั้นหนังสือ — ทุกเรื่อง จำนวนตอน ปุ่มอ่านต่อ |
| `/novel/<ชื่อเรื่อง>` | สารบัญ แบ่งหน้า (`?page=1&size=100`) + ค้นหาชื่อตอน (`?q=คำค้น`) |
| `/read/<ชื่อเรื่อง>` | เด้งไปตอนที่อ่านค้าง ถ้าไม่เคยอ่านไปตอนแรก |
| `/read/<ชื่อเรื่อง>/<ตอน>` | หน้าอ่าน |
| `POST /api/reader` | บันทึกตำแหน่งที่อ่านค้าง |

หน้าอ่าน: `←` `→` เปลี่ยนตอน, ปุ่ม **⚙ การอ่าน** ตั้ง theme (สว่าง/มืด/ซีเปีย) ขนาดตัวอักษร ระยะห่างบรรทัด ย่อหน้า ระยะห่างย่อหน้า

## ข้อมูล

อ่านจาก `NOVEL_DATA_DIR` โดยตรง (หรือ `data/` เมื่อไม่ได้ตั้งค่า) ไม่มีการ import:

```
data/
  reader.json                 ← ตำแหน่งที่ค้าง (ไฟล์เดียวที่เว็บนี้เขียน)
  <ชื่อเรื่อง>/
    _novel.json               ← สถานะ, genres, ต้นฉบับ
    chapters/<ตอน>/final.txt  ← ข้อความที่แสดง (ไม่มีก็ใช้ draft.txt)
```

- **ชื่อเรื่อง** = ชื่อโฟลเดอร์ **ชื่อตอน** = บรรทัดแรกของ `final.txt`
- ตอนที่ยังไม่มี `final.txt` หรือ `draft.txt` จะไม่ขึ้นในสารบัญ
- ตอนแทรกอย่าง `0421-x01` เรียงต่อจาก `0421` ให้เอง
- ค้นหาได้ทั้งชื่อตอนและเลขตอน (พิมพ์ `421` เจอทั้ง `0421` และ `0421-x01`) ครั้งแรกของแต่ละเรื่องช้ากว่าเพราะต้องอ่านหัวไฟล์ทุกตอน จากนั้น cache ไว้
- แปลตอนใหม่เพิ่มไม่ต้องรีสตาร์ต — cache ดูจากเวลาแก้ไขของโฟลเดอร์ `chapters/`
- `raw.txt` (ต้นฉบับจีน) กับ `index.sqlite` ไม่ถูกใช้ และไม่มีอะไรในเว็บนี้เขียนทับไฟล์นิยาย

`reader.json` ใช้รูปแบบเดียวกับโปรเจกต์ Translator ตำแหน่งที่อ่านค้างไว้เดิมจึงใช้ต่อได้ทันที ส่วน theme, ขนาดตัวอักษร และระยะห่างต่าง ๆ เก็บใน `localStorage` ของเบราว์เซอร์นั้น จึงไม่เปลี่ยนตามกันระหว่างเครื่อง

## โครงสร้างโค้ด

```
server.js              routes ทั้งหมด
lib/store.js           อ่าน data/, cache รายชื่อตอน, กัน path traversal
lib/chapter-text.js    แยกหัวข้อ/เนื้อจากข้อความตอน
lib/prefs.js           อ่าน/เขียน reader.json
views/*.ejs            หน้าเว็บ
public/css/app.css     สไตล์ + 3 theme ของหน้าอ่าน
public/js/reader.js    สไลเดอร์, theme, จำตำแหน่ง, คีย์ลัด
```
